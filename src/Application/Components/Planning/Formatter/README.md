# Planning Formatter

This formatter is used to return planning of the participant, sheet and of unallocated meeting request

This formatter return a formatted planning in markdown style

Example of return for the participant

**Jeudi 2 février 2017**

- 10:30 - 10:55 : Table F04 - XXXX
- 11:00 - 11:25 : Table E06 - YYYY
- 11:30 - 11:55 : Table B04 - ZZZZ
- 12:00 - 12:30 : SUB-EVENT 1
- 12:00 - 12:30 : MASS UNAVAILABILITY TITLE 1
- 12:30 - 14:00 : MASS UNAVAILABILITY TITLE 2
- 14:00 - 14:25 : Table D04 - OOOOOO
- 14:30 - 16:00 : Unavailable
- 16:00 - 17:00 : Unavailable message

Example of return for the unallocated:

Liste des rendez-vous validés non organisés faute de disponibilités réciproques

Company XXXX, Group YYYY, DDDDD Corp
